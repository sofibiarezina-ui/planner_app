# Planner TWI - Умный Планировщик Задач

Planner TWI — это полнофункциональное веб-приложение на базе Streamlit для управления временем, предотвращения выгорания и автоматического планирования расписания.

## Основные возможности
* Автоматическое расписание: Умный алгоритм планирует плавающие задачи в свободные окна с учетом рабочих часов и обеденного перерыва.
* Матрица Эйзенхауэра: Интерактивное распределение задач по важности и срочности с возможностью быстрого переноса в календарь.
* Совместные события: Предлагайте встречи другим пользователям системы (с проверкой их расписания на конфликты).
* Сохранение сессии: Вы не выйдете из аккаунта при случайной перезагрузке страницы (используются Cookies).
* Meme Zone: Библиотека мемов от пользователей для снятия стресса.

## Технологии
* Python 3.9+
* Streamlit — frontend и роутинг.
* SQLAlchemy (SQLite) — ORM и база данных.
* Bcrypt — безопасное хэширование паролей.
* extra-streamlit-components — управление Cookies.

## Структура проекта
**app.py** — главный файл интерфейса и маршрутизации.
**database.py** — инициализация БД и ORM модели.
**crud.py** — функции для взаимодействия с базой данных (CRUD операции).
**auth.py** — логика авторизации, регистрации и управления Cookies.
**utils.py** — вспомогательные функции (расчет времени, проверка конфликтов).
**algorithm.py** — логика автоматического распределения задач.
**calendar_view.py** — HTML-рендер бокового мини-календаря.

## Установка и запуск

1. Клонируйте репозиторий:
   `bash
   git clone <url_вашего_репозитория>
   cd <имя_папки>

2. Установите зависимости:
   `bash
   pip install -r "requirments.txt"
3. Запустите приложение:
   `bash
   streamlit run app.py
4. Откройте браузер по адресу:
   http://localhost:8501/
